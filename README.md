# miblog

Scaffold mínimo de blog en Astro.

## Scripts

- `pnpm dev`
- `pnpm build`
- `pnpm preview`
- `pnpm test`

## Estructura

- `src/content.config.ts` — colección tipada de posts
- `src/pages/` — home y páginas de detalle
- `src/layouts/` — shell compartido
- `src/components/` — piezas reutilizables
- `src/styles/global.css` — estilos globales
